# Daily Design: free-forever archive

This repository holds the historical **free-forever** Daily Design editions and reports, dated through **October 31, 2026**:

- `editions/<date>/<slot>.html`: the 7 AM (morning) and noon editions, with their header images
- `reports/<date>/<slot>.md`: the 6 PM (best) and 8 PM (hottest) reports, with their header images
- `data/meta/<date>/<slot>.json`: each edition's metadata

It is an archive and gets no new editions. Daily Design itself, with every edition, lives at
**https://studios.greatcreations.art/daily-design/**.

Daily Design is a Great Creation Studios brand.
